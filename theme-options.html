VoicePill — Theme & Button Picker

Red is the one accent, reserved for the mic (idle dot + listening). Everything else is neutral so the app feels like one piece. Pick a button variant, then check the composed light + dark themes below.

Button variants — pick one

Each card shows the Copy / Paste pair (history actions) and a single Download (settings). The current app uses red gradients + a too-dark ghost Paste — all of these are flat and cohesive. Toggle Dark/Light in the header to judge both.

A — Monochrome red only for mic

Actions are neutral; red is never spent on buttons. Most cohesive, calmest. Primary = raised fill, secondary = outline.

B — Solid red primary strong CTA

Primary action is solid red, secondary is a solid neutral chip with a clear border (fixes the dark Paste). Flat, no gradient.

C — Soft tint subtle

Red text on a faint red fill for primary; quiet ghost for secondary. Hints at the accent without shouting.

D — Outline light & airy

Red outline primary, neutral outline secondary. Equal weight, very clean — reads well in light mode especially.

E — Ink primary high contrast

Primary is the foreground color inverted (near-black on dark→light), secondary is a neutral chip. Maximal legibility, zero color noise.

How to tell me

Reply with the letter (e.g. “go with B”). Mix is fine too — e.g. “B primary but A secondary”. I’ll wire it into styles.css, drop the accent picker, and lock the red.
